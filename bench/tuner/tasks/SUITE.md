Each task asks one question about a parts depot. The agent must call the tools of the MCP server `depot` (search, stock, price, reserve, confirm) and write the answer to `answer.txt`. The depot accepts only its own input formats and gives each task a small quota of calls. A depot call can succeed and still return data that is not the data that the task needs. The questions use different parts, regions, dates, and quantities in each task.
